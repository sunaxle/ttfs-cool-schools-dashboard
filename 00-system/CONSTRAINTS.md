# 🛡️ Buzz Attack System Constraints (00-system/CONSTRAINTS.md)
## Texas Trees Foundation (TTFS) × UTRGV Project Cool Schools

Every worker, subagent, and script operating within this workspace must strictly uphold the following constraints:

---

### 1. Zero File Destruction Constraint
- **Rule:** Never delete, purge, or overwrite existing user code, markdown documentation, datasets, or media.
- **Rule:** All new features, refactors, and extensions must be additive and layered systematically.
- **Rule:** Legacy endpoints and files must maintain functional backwards compatibility.

### 2. Privacy-First Constraint (COPPA / FERPA)
- **Zero PII:** No personally identifiable student information (names, IDs, photos, exact addresses) may ever be stored or rendered in client-side storage, logs, or databases.
- **Campus-Level Aggregation:** All student engagement metrics (tree tags, quest completions, habitat sightings) must be aggregated anonymously at the campus level.
