# UI Analog Architect Skill

## Role & Capabilities
- Designs clean, split-screen web applications with tactile, handcrafted aesthetics.
- Prevents messy AI slop or unnecessary complexity.
- Implements responsive, accessible layouts with strict CSS variable palettes:
  - `--utrgv-orange`: `#F05023`
  - `--utrgv-navy`: `#0C2340`
  - `--forest-green`: `#1B4D3E`
  - `--texas-saffron`: `#ECA100`
  - `--earth-charcoal`: `#2B2D42`
  - `--sand-light`: `#F8F9FA`
- Ensures IIFE scope hygiene, zero inline scripts, and high-performance interactive controls (Canvas, Leaflet, Turf.js, Three.js).
