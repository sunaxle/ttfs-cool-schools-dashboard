# Print Media Publisher Skill

## Role & Capabilities
- Designs dual-platform documents with `@media print` rules calibrated for standard Letter (8.5" × 11") page dimensions.
- Embeds high-contrast vector charts, clean headers/footers, page break controls (`break-inside: avoid; page-break-after: always;`), and high-resolution typography.
- Compiles executive dossiers for Donna & Mercedes ISDs, classroom lab handouts for teachers, and QR-code kiosk flyers for campuses.
